# Code of Conduct

## Our pledge

We want MemoryTree to be a place where people can discuss memory formats, privacy, and agent tooling without harassment or personal attacks. We welcome participants regardless of experience level, background, identity, or opinion.

## Expected behavior

- Be direct about technical problems and generous with the people solving them.
- Critique ideas and code, not individuals.
- Ask before sharing someone else's private messages, memories, logs, or credentials.
- Respect privacy: do not ask others to publish personal memory data or secrets.
- Accept that maintainers may reject a proposal for scope, security, or maintenance reasons.

## Unacceptable behavior

- Harassment, threats, discrimination, or sustained personal attacks.
- Publishing private information, credentials, or memory data without permission.
- Deliberately derailing technical discussions.
- Using the project's name or spaces to endorse unrelated products or views.

## Enforcement

Report concerns privately to the maintainers through the repository profile or a private security/contact channel. Reports will be reviewed in good faith. Maintainers may edit or remove comments, close threads, or ban participants when necessary.

This is a small project; enforcement is intentionally lightweight but applies to issues, pull requests, discussions, and any project-affiliated space.
